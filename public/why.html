Engineering lessons

How good engineers worked here.

These are the habits worth stealing: test the story, enforce rules on the backend, keep docs separated by purpose, and make bugs pay rent.

Protect the core experience

The core is not Cloudflare, WebSockets, or React. The core is hidden-identity racing with one shot. Every technical choice should make that clearer or easier to test.

Backend rules beat disabled buttons

The UI can hide Start game from guests. The Worker still has to reject non-host countdown requests. Frontend constraints guide honest users; backend constraints protect the shared state.

Verify where the risk lives

Unit tests catch logic lies. Browser tests catch integration lies. Live deploy checks catch environment lies. We needed all three.

UI should earn its space

The Sync label and sidebar were useful while debugging. Once the game worked, they became noise. Good UI hides machinery when players no longer need it.
