# Death Race

Browser-playable hidden-identity racing/shooting game.

## Commands

```powershell
npm run dev
npm run lint
npm run build
npm run preview
```

## Project Docs

- `spec.md`: game design and technical shape.
- `progress.md`: completed work and current state.
- `todo.md`: remaining work.
